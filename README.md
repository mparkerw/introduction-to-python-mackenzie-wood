# Introduction to Python

Coursework for Introduction to Python (Prof. Ali Massoud), EPITA, Fall 2026.

**Author:** Mackenzie Wood

## Assignments

| File | Description |
| --- | --- |
| `Best_Student.py` | Finds the student with the highest grade |
| `Grade_Classifier.py` | Classifies grades into categories (e.g. Very good, Good, Pass, Fail) |
| `Number_Guessing_Game.py` | Guess-the-number game using loops and user input |
| `Quiz_Correction.py` | Checks quiz answers and calculates a score |
| `Safe_Calculator.py` | Calculator that handles invalid input and errors with try/except |

## How to run

Requires [uv](https://docs.astral.sh/uv/) and Python 3.14+.

    uv run python Best_Student.py

Replace the file name to run a different program.
